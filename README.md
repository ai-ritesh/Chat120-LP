# Chat120-LP: Landing Page for Chat120

Welcome to the **Chat120-LP** repository! This is the official landing page and marketing site for the **Chat120** application — a modern AI-powered chat application built with Google's Gemini API.

## 📋 Overview

**Chat120-LP** serves as the public-facing landing page that introduces and promotes the Chat120 application. This repository works in conjunction with the main Chat120 application repository to provide:

- 🎯 An engaging landing page to attract users
- 📱 Responsive design for all devices
- 🔗 Direct links to the live Chat120 application
- 📢 Project information and features showcase
- 🚀 SEO-optimized content

## 🚀 Quick Start

### Prerequisites
- Basic web browser
- (Optional) Node.js for local development

### Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ai-ritesh/Chat120-LP.git
   cd Chat120-LP
   ```

2. Install dependencies (if applicable):
   ```bash
   npm install
   ```

3. Start a local development server:
   ```bash
   npm run dev
   # or
   python -m http.server 8000
   ```

4. Open your browser and navigate to `http://localhost:8000`

### Deployment

This repository is set up with **GitHub Pages** support. Push changes to the `main` branch to automatically deploy your landing page.
