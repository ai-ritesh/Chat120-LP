What is Chat 120?

Chat 120 is a web-based private messaging project focused on ephemeral communication. The service is designed around temporary 120-minute chat sessions rather than permanent conversations.

Users can start a temporary conversation without the traditional phone-number or email signup flow. Depending on the deployed version, Chat 120 can provide encrypted messaging, file sharing, code sharing, QR-based peer discovery and WebRTC audio communication.

Chat 120 is intended for users who want a lightweight temporary communication experience without maintaining a conventional permanent messaging account.
